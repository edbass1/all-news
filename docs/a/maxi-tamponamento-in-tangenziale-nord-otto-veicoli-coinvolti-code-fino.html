Maxi tamponamento in tangenziale nord: otto veicoli coinvolti, code fino a sera

Un ferito lieve tra Regina Margherita e Venaria in direzione Milano-Aosta.

Otto veicoli sono rimasti coinvolti in un tamponamento a catena nel tardo pomeriggio di mercoledì 14 ottobre sulla tangenziale nord, tra gli svincoli di corso Regina Margherita e Venaria Reale, in direzione Milano-Aosta.

Una persona è stata portata in ospedale con ferite non gravi. Le code si sono protratte fino alla prima serata, con rallentamenti anche nella carreggiata opposta per i curiosi.
